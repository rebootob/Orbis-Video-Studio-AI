## 1. Mode-Aware End-to-End Flow

```mermaid
flowchart TD
    P[Create Project] --> M{Select Video Mode}
    M -->|STORY| S1[Story -> Script -> Scenes -> Shots]
    M -->|SHORT| S2[Hook/Concept -> Scene -> Shots]
    M -->|LOOP| S3[Loop Spec -> Shot(s)]
    M -->|SCENE| S4[Scene -> 1-N Shots]
    S1 --> R[Reference Mapping]
    S2 --> R
    S3 --> R
    S4 --> R
    R --> G[AI Generate via Provider Adapter OR Import Media]
    G --> L[Review & Lock Approved Assets]
    L --> A[Audio / Subtitle / Timeline as applicable]
    A --> Q{QC & Human Approval}
    Q -->|Needs revisions| X[Selective Regeneration of Unlocked Shots]
    X --> A
    Q -->|Approved| C[Cloud Final Render]
    C --> O[Multi-Output Export]
```

## 2. Stage-by-Stage Journey

### Stage 1 — Project Setup

User creates a project and selects:
- Video Mode
- Purpose
- Target Platform
- preferred aspect ratio / duration where known
- brief, documents, prompts and references

### Stage 2 — Mode-Aware Creative Structure

- **STORY:** system supports Story synopsis, Script, Scenes and Shots.
- **SHORT:** system may use Hook/Concept, compact Scene and Shots without full Story.
- **LOOP:** system may begin from prompt/references and Loop Specification without Story or Script.
- **SCENE:** system may begin from one Scene and 1-N Shots.

The system generates only the structural layers required by the chosen mode.

### Stage 3 — Reference Library & Continuity

User assigns Character, Location, Style, Brand, Document and other relevant references. Factual and locked references take priority over AI creativity.

### Stage 4 — Hybrid Shot Production

Each shot can be AI-generated or sourced from imported video, image, recorded footage, stock media or a mixed workflow.

AI generation always goes through the provider-neutral generation service / durable queue, never directly from core Shot logic to Vidu.

### Stage 5 — Review, Lock & QC

Approved entities can be locked. Locked items cannot be silently overwritten or regenerated.

### Stage 6 — Audio / Subtitle / Timeline

Where applicable, user configures dialogue, VO, BGM, SFX, subtitles, ducking and simplified timeline placement/trimming.

### Stage 7 — Selective Revision

Only affected unlocked or failed shots are regenerated by default. The system must not silently regenerate the entire project.

### Stage 8 — Human Approval & Export

After QC, explicit human approval gates final cloud render. One master project may produce multiple approved output variants such as 16:9, 9:16 and 1:1.

## 3. Workflow Rule

Story is not mandatory for every Project. `video_mode` determines which creative stages are required.

See [`VIDEO_PRODUCTION_MODES.md`](VIDEO_PRODUCTION_MODES.md) for canonical mode behavior.
