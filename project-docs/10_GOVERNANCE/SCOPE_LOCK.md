## 1. Locked Architectural Principles

The following principles are locked by Owner directive unless formally amended:

1. **Mode-Aware Structured Production:** Core V1 supports STORY, SHORT, LOOP and SCENE. STORY uses the full narrative path; other modes may bypass unnecessary Story/Script layers.
2. **Narrative Continuity Where Applicable:** STORY and other multi-shot productions optimize for flow, continuity and cross-shot consistency without forcing every Project to contain a Story.
3. **Reference-Driven Production:** Centralized Character, Location, Document, Prop, Brand, Style, Image, Existing Shot and Audio references.
4. **Hybrid Shot Workflow:** Shots may be AI generated, imported video, imported image, recorded footage, stock media or mixed.
5. **Asset Locking:** Approved Script, Scene, Shot, Character, Location, Voice and Timing entities can be explicitly locked.
6. **Vidu-First Provider:** Vidu is the V1 default video provider.
7. **Provider Independence:** Provider-specific logic remains behind adapter boundaries; core domain code does not call Vidu directly.
8. **Cloud-First:** No local GPU or local AI runtime dependency.
9. **Comprehensive Audio Pipeline:** Dialogue/Dubbing, VO, original audio, BGM, SFX, subtitles and auto-ducking are planned Core V1 capabilities.
10. **Simplified Timeline:** Production-focused timeline, not a Premiere-class NLE.
11. **Selective Regeneration:** Only target missing/failed/selected unlocked shots are regenerated by default.
12. **Cost & Usage Tracking:** Provider/job/model/retry/shot usage and cost must be auditable.
13. **Human Approval Gates:** Final render and protected cost-sensitive actions remain human governed.
14. **Multi-Output Readiness:** One master project supports multiple aspect ratios/languages/presets without rebuilding the production.
15. **Integration-Ready Architecture:** Preserve REST/webhook/auth/permission/audit/idempotency boundaries for future Hermes/n8n operations.

## 3. Core V1 Production Flow

```text
Create Project
-> Select Video Mode
-> Add Brief / Script / Documents / Prompt / References
-> Build only required creative layers
-> Scenes / Shots
-> Vidu generation through provider adapter and/or imported media
-> Lock approved entities
-> Dialogue / VO / Music / Subtitle where applicable
-> Simplified timeline
-> Selective regeneration
-> Cost / usage safeguards
-> Human approval
-> Cloud render
-> Final MP4
-> Approved multi-output variants
```

Full Hermes/n8n operational integration remains POST-CORE V1 / V1.x unless separately authorized.
